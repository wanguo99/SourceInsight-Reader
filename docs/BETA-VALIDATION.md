# Beta 用户任务与结果模板

本文是待执行流程，不含伪造的用户反馈。目标 20～30 位不同背景参与者，覆盖嵌入式 C、Linux/系统 C/C++、桌面 C++、Java、Python 和经常使用 Remote 的读者。记录公开可分享结果，私有工程不随报告上传。

每位参与者使用干净 Profile，不接受作者口头引导，完成以下任务：

1. 安装后通过指南判断自己的工程具备哪些能力。
2. 五分钟内找到一个实际被调函数，预览定义，说明谁调用它。
3. 找出同一调用边的两处现场，区分函数引用与同名文字搜索。
4. 修改一个未保存文件，判断结果是否及时更新/过期。
5. 保存笔记和阅读任务，重载后恢复；检查符号位置漂移。
6. 搜索跨行代码并保存查询；改变屏蔽范围后复查结果。
7. 遇到缺语言服务/数据库时，利用诊断自行找到下一步。

独立完成率目标 90%，目标不是当前成绩。按项目类型分别统计耗时、失败率、错误跳转和理解成本；不要仅记录“好用/不好用”。发布前必须解决错误确定跳转、配置/笔记破坏、稳定复现的挂起和首任务主要障碍。其余问题进入下一轮可核对的优先级清单。
