# SourceInsight-Reader

1. **Diagnose / 能力诊断**: confirm the language service and compilation database. Local C results do not evaluate conditional compilation.
2. **Read / 阅读**: preview a definition in Context; browse calls in Relation; use Lookup References for bound references and text search for literal, regex or multiline matches.
3. **Choose / 选择**: existing editor keys and layout are preserved by default. The keyboard and layout presets are explicit commands. clangd configuration changes have a diff preview.
4. **Resume / 恢复**: bookmarks, notes, saved searches and reading tasks stay in workspace extension storage. Changed source anchors are relocated only when unique.
