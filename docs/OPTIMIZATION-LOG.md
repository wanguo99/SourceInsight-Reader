## S1 准确性

- 修复文件级/头文件声明的回调变量遮蔽同名函数、原型参数独立作用域、不可见枚举与类型绑定。
- C++ 语法头文件不交给 C grammar；已打开的 C++ 头文件由语言服务处理。解析事实版本升至 facts-7。
- 工程根身份不再随屏蔽列表合并；独立范围指纹继续隔离异步覆盖；排除工作区目录保留外部 SDK 预览，非法规则仍拒绝查询。
- UTF BOM 和显式 files.encoding 解码；非法字节/NUL 明确失败。逐文件失败跨无关更新保留，失败文件退出有效索引，恢复后仅清除自身错误。
- Java/Python/大写后缀的外部变更使 Relation 失效。
- 新增 `test/commercial-correctness.test.js` 八个回归，包含真实 WASM 和 Worker；完整单测从 231 增至 239。日志位于 `/tmp/sourceinsight-s1-{check,unit,clangd,package}.log`，不作为可移植发布证据。
- 本轮未计宿主或其他平台通过。后续 S5 增加有界宿主运行和平台流程。

## S2 查询与结果

- 新增查询协调器：相同在途请求合并、每通道并发预算、等待超时、代次取消；超时实际工作保留槽位，避免软超时导致无限后台请求。
- 定义采用短语义预算加有界 C 回退，支持 auto/local/languageService；Context 显示来源。本插件原生本地定义提供者在内部语义探测时退出，避免把自身语法结果标成语义结果。
- 非 C 文件符号、定义、声明、引用和语义调用层次均有预算；语义句柄在取消后不重新进入新代次。引用未提供能力与确认空结果区分。
- Relation auto 优先语义，保留显式 local；编译命令、编译 flags、CMake presets、文件关联和 clangd 参数参与配置身份/失效，build 目录中的编译配置也生效。
- 新增 `test/query-coordinator.test.js` 七项，包括永久挂起、实际在途限流、来源防混淆、配置切换。基础 C 仍不求值预处理；编译参数的语义解释由语言服务提供，S4 诊断界面展示配置状态。

## S3 性能与完整浏览

- 依赖反向索引与包含闭包 LRU（最多 32768 个成员、64 个集合），批量更新一次提交图版本；无变化快照不重写，持久化分片让出 Worker。
- 文件元数据复用缓存；强制扫描重新读内容。当前文件优先，首批 16 文件快照可阅读；枚举 30 秒、在线无进度 60 秒看门狗，解析/提取各 3 秒，Worker 堆预算 512 MiB。
- 全文匹配移到独立可终止 Worker；预览先显示源码，基础高亮分片，TextMate 复用同文档文本镜像。高亮结果按版本丢弃过期响应。
- 文件普通浏览按目录加载，搜索不再先截断；文件、文档符号和关系支持继续加载。目录符号链接跳过，条件排除使用提供者枚举。
- 实机发现并修复设置文件通知及迟到 create 通知取消当前预览、函数头强调在异步查询间丢失。缓存仅在文档身份、版本、配置和范围均一致时复用；源码编辑不自动重试旧坐标。
- C 兼容头文件不会仅因编辑器默认 cpp 标记而失去离线能力；显式 C++ 关联或 C++ 语法仍拒绝。范围指纹使用 SHA-256，扫描与覆盖同时校验范围和 indexExclude。
