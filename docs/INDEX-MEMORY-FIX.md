# 1.1.0 本地索引内存修复

针对用户的 openairinterface5g 工程，已只读复现并修复 `Worker terminated due to reaching memory limit: JS heap out of memory`。修复首先在1.1.0本地验收包验证，现按用户指定整合为1.0.10发布包；源码目录没有修改，测试缓存与日志使用临时目录。下方保留原始工程测量记录。

## 复现与结果

Node22.23.3 / Linux，以默认排除规则枚举 7263 个 C/H 文件，源码约65.5MiB。直接使用实际索引Worker，优先 nr-softmodem.c；该过程是Worker工程实测，不等同完整VS Code界面/全工程语义准确性验收。

| 场景 | 堆上限 | 结果 | 实测时间 / 内存 |
| --- | --- | --- | --- |
| 修复前冷扫描 | 512MiB | 在进度1056处复现相同OOM，Worker退出 | 约15.1秒 |
| 修复后强制全量解析 | 1024MiB | 扫描结束，7251文件收录、12文件单列跳过 | 约45.2秒；完成时JS堆500MiB、ArrayBuffer69MiB |
| 流式缓存重载 | 1024MiB | 收录数量一致，代表性定义查询通过 | 约19.7秒；完成时JS堆356MiB、ArrayBuffer69MiB |
| 同一Worker连续重建 | 1024MiB | 先载入7251文件，再强制重建仍为7251，无OOM | 重建段约39.1秒；完成时JS堆500MiB |

机器可读结果见 [index-memory-oai.json](validation/index-memory-oai.json)，包含后续重载结果（最近一次缓存重载约9.9秒）。一次运行的进程RSS曾约1.1GiB，包含主线程、Worker、WASM等，不能把JS堆值理解为进程总内存。测量是本机单次数据，非跨平台性能保证。

12个跳过文件包括C++头文件、编码不匹配及超过8MiB的sqlite3.c；这些不是OOM，也不能记成全部解析成功。索引内的3579个文件存在Tree-sitter C未解析内容，宏/条件分支等可能导致此状态，不等同于编译器判定源码有语法错误。完整编译语义仍依赖语言服务。

## 修复内容

1. 标识符的重复名称和位置对象改为名称表与Int32Array；查询仍使用UTF-16坐标，保留类型标签和字段接收者，覆盖缓存往返与引用回归。
2. 共享符号位置/字符串，复制名称以避免短切片长期保留整份源码；数值生成表保留变量声明，避免逐个构造数百万个无可导航符号的AST叶节点。含变量/宏的初始化表达式继续解析。
3. 歧义调用只存候选数量，确定调用只存唯一目标；不再为每个调用点复制全部候选ID形成笛卡尔积，歧义仍显示为调用现场。
4. 缓存仍为合法version2 JSON，但每个文件独占一行，流式加载；超大旧单行缓存有界读取后丢弃重建；packed事实版本升级facts-8，自动使旧解析缓存失效。
5. 扫描期间暂停持久化计时器，写缓存只抓取单个当前事实，不保留整批旧事实对象；强制重建先释放旧图和旧事实，避免新旧完整索引同时常驻。
6. 增加 indexMemoryLimitMb：默认1024，范围128～8192，单位MiB。新文件准入采用较低软预算并为解析/关系图留余量；触及软预算保留明确标记的部分结果及未收录数量，不能把未收录文件标ready或把关系结果称完整。
7. 真正OOM后清空旧快照、拒绝挂起请求、停止自动重启。修改内存上限/屏蔽范围，或主动运行重建命令后可恢复。单纯反复自动查询不会再次创建Worker。
8. 诊断导出增加堆/ArrayBuffer、上限、部分标记与未收录数量；仍不导出源码或路径。

## 验证与用户步骤

新增真实WASM/Worker、低堆预算、数值大表、歧义边、流式缓存、旧大缓存、OOM恢复和覆盖范围回归；全量310项单元测试与check通过，构建/制品校验通过；实际VSIX安装宿主18项通过、1项因clangd19不支持outgoing而跳过。验收项 IDX-08、IDX-09、FAULT-06 已并入完整用例。

导入1.0.10发布包并重载窗口，运行“SourceInsight-Reader: 重建本地 C 调用索引”。无需删除源码或手动清空存储；当前facts-9自动失效旧缓存。先使用默认1024MiB；更大工程可按实际内存情况调整 indexMemoryLimitMb 或缩小范围。若内存受限会明确说明结果不完整，不能把设置成更大数值等同于已经获得完整编译器语义。后续漏收录、兼容头文件、编码和大文件受限模式的修复见 [INDEX-COVERAGE-FIX.md](INDEX-COVERAGE-FIX.md)。
