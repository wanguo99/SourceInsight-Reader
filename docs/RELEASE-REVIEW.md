# 1.1.6 重新发布检查

检查日期：2026-10-30。按用户指定将当前修复代码重新发布为 1.1.6，保留此前 1.1.7 的功能；第三方依赖不变。历史标签和安装包保留，本次使用独立 annotated tag `1.1.6-rebuild.1`。

## 发布行为

- 修复着色缓存未跟随索引线程内绑定更新的问题；定义查询补齐头文件后重查颜色，未保存内容按当前编辑快照校验。主编辑器与 Context 共用确认绑定，函数指针调用按函数显示，未绑定名称使用默认前景色。
- 修复仅含 struct 的 C++ 头文件识别、复合返回类型回调声明、文件编码、仅语言服务导航模式和主题切换失效问题。
- 改进 extern 定义和宏作用域绑定，保留条件宏与真实多定义歧义；39 个准确性场景同时验证内存索引和 SQLite 重开。
- 缓存升级到 schema 6，以整数关联压缩重复路径和调用字段；旧库分批迁移并支持中断恢复，损坏记录局部重建，满足空间条件时回收空闲页。
- 保留工程导入范围隔离、宏候选标记及 Context 单个开始 / 刷新索引按钮。
