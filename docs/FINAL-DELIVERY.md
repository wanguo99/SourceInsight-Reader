## 用户验收顺序

1. 复制验收工程与 CSV 模板，校验/安装最终 VSIX，用干净 Profile 跑 FIRST、FILE、SYM、CTX、REL、REF、SEARCH、NAV。
2. 再跑 READ、SCOPE、IDX、SET、KEY、LAYOUT、CLANGD 和 ENV。共享配置与故障测试使用工程副本；默认不自动启用经典键位或clangd维护。
3. 在你实际使用的 Windows/macOS/Remote 和 Java/Pylance 环境执行对应组。缺环境写 BLOCKED，缺提供者能力写 N/A，不填写 PASS。
4. 最后执行读屏/高对比/缩放、八小时稳定性、真实大型工程性能、跨版本升级/回滚与Beta任务。

若出现错误确定跳转、源码/共享配置被覆盖、笔记破坏、稳定挂起，应先阻断正式发布。性能/语义准确率必须按真实项目采样，避免用本机合成与模拟测试替代商用证据。
