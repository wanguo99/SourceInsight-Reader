# Release versions

The user requires a new version for each subsequent change. Version iteration restarted at 0.10.1; increment the patch version for each later requested change and rebuild the VSIX. Do not reuse 1.0.0 or repeatedly overwrite a released version. Keep package.json, the root package-lock.json version fields, installation instructions, and the latest changelog entry consistent. Do not change third-party dependency versions when updating the extension version.
